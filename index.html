Why I Study Web Design

I study web design because it is an important part of my Software Engineering journey. Web Design is a new module that was introduced to me, and at first, I saw it as just another course. However, I have become interested in it because I now understand how useful websites are in education, business, communication, and personal branding.

Learning web design helps me understand how websites are created and how information can be arranged clearly for users. It also helps me improve my creativity because I get to think about layout, structure, content, and how a webpage should look. I believe web design will help me in my future career because I will be able to create websites, portfolios, and digital platforms that are useful and professional.
